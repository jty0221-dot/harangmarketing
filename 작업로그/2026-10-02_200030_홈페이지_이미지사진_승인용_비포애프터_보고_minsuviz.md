## 1. 결론

홈페이지의 사진 품질이 전반적으로 낮은 것이 아니라, 좋은 실사 자산이 사진 서비스 안쪽에 몰려 있고 구매 결정이 일어나는 홈·회사소개·업종·진행과정 화면에는 거의 나오지 않는 것이 핵심 문제다.

현재 운영 화면에서 확인한 주요 사실은 다음과 같다.

- 홈은 18.8초, 1920×1080 영상 한 편이 첫 화면 전체를 책임진다. 영상은 사무실 업무 장면이나 프레임 자체가 흐리고 어두워, 하랑의 실제 사람·업무·성과를 또렷하게 증명하지 못한다.
- 회사소개는 로고 두 개 외에 실사 사진이 없다. 코드에서도 `SHOW_PHOTO = false`다.
- 진행사례, 상담, 진행과정, 지역 안내도 로고 외 실사 이미지가 없다.
- 서비스 허브는 실제 납품물과 사진을 17개 보여줘 강하다. 다만 서로 다른 비율과 스타일의 캡처가 한 화면에 섞인다.
- 사진촬영, 상세페이지, 인스타그램, 포트폴리오는 실물 자료가 충분하다. 이 자산을 홈과 업종 페이지에서 고객 질문에 맞게 선별해 재사용하면 신규 생성보다 신뢰도가 높다.
- `public`에는 사진·캡처가 충분하다. 주요 묶음은 사진 협력사 396개 363.78MB, 카페 레퍼런스 2,520개 122.32MB, 상세페이지 138개 63.90MB, 사진 가격·표지 35개 23.09MB, 인스타 하이라이트 85개 6.77MB, 포트폴리오 119개 6.48MB다.

첫 승인 묶음은 1) 홈 첫 화면 영상 교체, 2) 대표 실사 촬영과 회사소개 반영, 3) 서비스·업종 화면의 실제 결과 모듈 통일, 4) 포트폴리오 썸네일 품질 선별이다. 이 네 건이 전체 인상을 가장 크게 바꾼다.

## 2. 고객 감정 기준

### 확인 사실

- 홈페이지는 현재 상태 진단, 대표 직접 관리, 실제 계측, 실제 납품물을 핵심 약속으로 사용한다.
- 사진 서비스와 상세페이지·인스타 레퍼런스에는 실제 결과물이 이미 있다.
- 홈과 회사소개에는 대표 인물 사진이 노출되지 않는다.

### 가설

- 처음 방문한 대표님은 화려함보다 ‘실제로 운영하는 회사인가’, ‘누가 내 일을 맡는가’, ‘어떤 결과물을 받는가’를 먼저 확인하려 한다.
- 흐린 연출 영상보다 대표의 실제 업무 장면, 실제 보고 화면, 실제 촬영 현장이 신뢰와 안도감을 더 빠르게 만든다.
- 업종별 화면에서 자기 업종의 실제 사례 한 장을 보면 긴 설명보다 상담 전 불안이 빨리 줄어든다.

### 확인 필요

- 대표 얼굴 공개 범위와 새 촬영 가능 일정
- 고객사 로고·매장·납품물의 홈페이지 재사용 동의 범위
- 원본 사진의 색보정 허용 범위와 촬영 협력사 크레딧 표기 필요 여부
- AI 생성 컷을 설명용 연출 이미지로 사용할지 여부

## 4. 유지할 것

- 사진촬영 서비스의 실제 음식·공간 자산은 현재 사이트에서 가장 강한 시각 증거다. AI 이미지로 교체할 이유가 없다.
- 상세페이지 납품물, 인스타 하이라이트, 카페 노출 캡처, 스튜디오 화면은 실물 증거이므로 생성형 이미지보다 우선한다.
- 파트너 로고는 자연 해상도 384×144에서 화면 155×58로 표시되어 해상도는 충분하다. 로고 자체를 AI로 다시 만들지 않는다.
- 홈 공유 카드에는 숫자를 넣지 않는 현재 원칙을 유지한다.
- 법률·개인정보·FAQ·환불·약관 페이지는 장식 사진을 추가하지 않는다.

## 6. 승인 단위와 예상 작업 순서

### 승인안 A · 신뢰 중심 핵심 개편

1. 대표 실사 촬영 3장과 8~12초 영상 소스 확보
2. 홈 첫 화면 영상과 포스터 교체 시안
3. 홈·회사소개 대표 신뢰 모듈 시안
4. 로컬 375·768·1280·1920 확인

효과: 첫 방문 10초 안에 실제 회사와 담당자를 보여준다.  
필요 승인: 촬영, 대표 얼굴 공개 범위, 최종 컷, 코드 적용, 배포.

### 승인안 B · 서비스 결과물 체계화

1. 서비스 허브 썸네일 비율 통일
2. 업종별 6페이지에 실제 사례 3장씩 선별
3. 진행사례에 증거 캡처 3단 카드 도입
4. 포트폴리오 119개 품질 등급화와 첫 노출 재선정

효과: 설명 위주의 페이지를 실제 결과 확인 페이지로 바꾼다.  
필요 승인: 고객사 재사용 동의 확인, 공개 범위, 코드 적용, 배포.

### 승인안 C · 제작물과 공유 카드 정리

2. 상세페이지·인스타 대표 사례 큐레이션

필요 승인: 최종 시안, 코드 적용, 배포.

## 7. 승인 전 금지선

- 기존 운영 이미지, 영상, 코드에 변경을 적용하지 않는다.
- 실제 직원·고객·매장을 AI로 생성해 실사처럼 표시하지 않는다.
- 고객사 실명·로고·매장 사진은 재사용 동의와 계약 범위를 확인하기 전 확대 노출하지 않는다.
- 의료 전후 사진과 치료 경험처럼 읽힐 소재는 진우 검수 없이 쓰지 않는다.
- 가격 문구와 제공 범위는 이미지 안에 새로 넣지 않는다. 가격 변경은 별도 C 결재다.
- 배포와 푸시는 별도 C 결재다.

## 8. 조사 근거

- 운영 페이지 12개를 브라우저에서 직접 확인했다: `/about`, `/services`, `/services/photo`, `/services/photo/price`, `/services/detail-page`, `/services/instagram`, `/portfolio`, `/cases`, `/studio`, `/contact`, `/process`, `/location`.
- 홈의 실제 화면과 이미지·영상 DOM을 확인했다. 영상은 화면상 약 1914×919로 표시되고 원본은 1920×1080이다.
- 저장소에는 공개 페이지 `page.tsx`가 57개 있으며, 관리자·보고서·SNS 계정 화면을 제외한 마케팅 핵심 페이지를 이미지 개선 대상으로 분류했다.
- 대표 이미지 규격 확인: `hero-v4-poster.jpg` 1920×1080, `og-image.png` 1200×630, 사진 가격표 6장은 1280px 폭, 상세페이지 대표 썸네일 560×747, 인스타 커버 720×720, 포트폴리오 대표 이미지 720×720.
- 현재 이미지·영상 원본은 변경하지 않았다.

## 9. 대표 승인 요청 문안
