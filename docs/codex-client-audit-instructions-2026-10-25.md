# Codex 실행 지시: 하랑마케팅 고객사 27곳 SEO/GEO 실사 및 개별 전달문 작성

원본: Google Sheets '하랑 마케팅' / '하랑 클라이언트 목록', E열 상태='진행 중'. 두꺼비 홈케어 중복행은 동일 사업체로 묶되 계약 건은 유지. 완료/종료/시작 안 함 제외.

## 절대 준수
- '관리명'을 '실제 브랜드명'으로 간주하지 말 것. 업체별 공식 플레이스 URL, 주소, 전화번호, 사업자 정보로 식별하고 증거 URL 저장.
- 사용자 확인 정본: 울산입주청소=열정클린; 세종 클린패스=클린패스; 의정부·양주 입주청소=청소GO; 군포 입주청소=두꺼비 홈케어; 부천누수=힘찬설비; 부천누수탐지=누수파이터. 나머지는 독립 식별 후 확정.
- 공개 웹 검색 발견과 ChatGPT 실제 추천 응답은 서로 다른 데이터. 브라우저 검색을 'AI 추천'이라고 표시하지 말 것.
- 질문은 브랜드 포함/미포함 각 3~5개 이상. 질문 전문, 날짜, 지역, 검색 사용 여부, 모델, 추천 순서, 출처 URL, 경쟁사, 판정, 캡처를 기록.
- 검색에 안 나오는 것과 미측정/도구 접근 실패를 구분. 실제로 실행하지 않은 질문은 '미실행'.
- 의료기관은 의료광고법/심의, 허위·과장 표현을 별도 검토. 리뷰 조작·허위 리뷰·알고리즘 가중치 창작 금지.
- 웹사이트 없는 업체에 무조건 새 홈페이지 권유하지 말고 플레이스/공식 SNS/업체 프로필의 실제 보강점부터 제안.
- 제안은 발견된 문제에 대한 근거와 적용 위치, 예상 효과(보장 아님), 담당자, 우선순위, 완료 확인법을 포함.
- 고객사 전달문에는 경쟁사 비방·미검증 실적·비공개 계약정보를 넣지 말 것.

## 조사 산출물
1. master.csv: 관리명/브랜드/지점/업종/지역/공식 URL/확인 근거/확인 일시/브랜드 검색/비브랜드 질문/실제 AI 응답/출처/개선 작업/상태.
2. clients/{slug}.md: 한 업체당 1페이지 이상, 확인 사실·검색 질문별 결과·경쟁사·3단계 실행안·고객 전달용 문구.
3. 전체 PDF: 요약, 업체별 분석, 방법론, 검증 로그, 미확인 사유.
4. 하랑마케팅 홈페이지 별도 보고: robots, sitemap, canonical, JSON-LD, llms.txt, 실제 검색 노출, 인용 출처, 전환 추적.
5. 완료 정의: 모든 업체/질문 실제 실행 로그가 있어야 전수조사 완료라고 표기.

## 2026-10-25 사용자 확정 추가 지시
- 청설모 토탈케어 부천점 별도 전화번호는 **의도된 서브폰**. 연락처 불일치 오류/수정 권고 금지. 포항·김포·부천 지점별 방문권역과 서비스 키워드 각각 검사.
- 정확한 브랜드 매핑: 청소GO(청소고), 두꺼비 홈케어, 열정클린, 클린패스, 힘찬설비(부천누수), 누수파이터(부천누수탐지).
- 모든 업종에 대해 지역×주요서비스×검색의도 키워드 매트릭스 작성. 예: 포항 청소업체/포항 식당청소/포항 후드청소, 부천 청소업체/부천 상가청소, 김포 청소업체/김포 입주청소.
- **월간 검색량**은 네이버 검색광고 공식 키워드 도구의 PC·모바일 수치를 기준월과 함께 조회해 기록. 권한이 없으면 숫자를 추정하지 말고 '공식 검색량 미조회'로 표시하며 계정 연결·내보내기 CSV 확보 작업을 명시. Google Trends 상대 지수를 절대 검색량으로 표시하지 않는다.
- 웹 검색 색인 발견, 네이버 플레이스 실제 검색 순서, ChatGPT 실제 추천 응답을 각각 독립 검증하고 혼합하지 않는다.
- 고객 전달용 보고서는 모바일 가독성 PDF로, '확인 사실 / 미확인 / 조치 / 담당자 / 우선순위 / 예상 확인일'을 표기한다.
- 코드로 자동화 가능한 사이트 개선과 고객 플레이스 관리자 권한이 필요한 수정은 분리한다.

## 2026-10-25 추가 확정 사항
- 청설모 토탈케어 부천점 연락처 차이는 **정상적인 서브폰 운영**이다. 연락처 불일치 오류로 보고하지 않는다. 실제 지점별 공식/서브 번호를 분리 기록한다.
- 청소GO의 표기는 GO 영문, 두꺼비 홈케어(도깨비 아님), 힘찬설비=부천누수, 누수파이터=부천누수탐지.
- 검색량은 네이버 광고주센터 > 도구 > 키워드 도구의 월간 PC/MO 검색수 및 조회 기준일을 정본으로 사용. 숫자를 조회하지 못하면 '미조회'로 두고 0으로 기록하지 않는다. 네이버 데이터랩의 상대지수는 절대 검색량이 아니다.
- 각 고객사의 실제 브랜드, 플레이스 표시명, 업종, 지역, 서비스권역을 분리. 포항/부천/김포 청설모는 지역별 각각 조사하되 같은 브랜드 계열로 묶는다.
- 각 키워드에 대해 월 PC/MO/합계, 조회일, 네이버 플레이스 노출(순위/광고 구분), 공개 웹 노출(출처 URL), 실제 ChatGPT 추천(질문/원문/추천 순서/출처/실행 환경)을 개별 필드로 수집.
- 전수조사 미완료 상태에서 완료 표시 금지. 고객별 1장 PDF를 포함한 전체 모바일 친화 PDF를 최종 납품.
- 개선 지시는 정확한 근거를 확인한 항목만. 기존 운영 사이트 수정은 민수 팀장 리뷰와 테스트를 거친 PR로 진행.
