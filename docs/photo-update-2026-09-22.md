# 사진촬영 가격·포트폴리오 업데이트

## 대표 지시와 기준

2026-09-22 본유 음식점 상품 구성과 사진을 적용하고 각 패키지에 10만 원을 더하도록 요청했다. 원본 PC와 모바일의 가격이 달라 질문했고, 대표가 PC 기준 30만·60만·100만 원을 선택했다. 이후 시설촬영도 별도 확인·업그레이드하고 업체 이름을 포함한 포트폴리오 목록과 업체별 자동 슬라이드를 요청했다.

## 가격 대조

모든 금액은 부가세 별도. 추가 컷 단가는 패키지 인상 대상이 아니므로 15,000원 그대로다.

수정은 모두 2회. 음식점 보정 진행, 시설 보정은 A컷에 한함.
음식점 원본 https://bornu.kr/42 · 시설 원본 https://bornu.kr/40.
시설 원본 모바일의 50만·80만·100만 원은 PC 기준과 달라 사용하지 않았다.
시설 페이지 하단 홍보 이미지에는 원본 가격표·QR·연락처가 포함돼 있어 하랑 상품 사진으로 사용하지 않았다. 상품별 상단 사진 3장을 사용했다.

## 포트폴리오

숙박 목록 https://bornu.kr/24 · 음식점 목록 https://bornu.kr/61.
숙박 24곳과 음식점 5곳을 원본 순서로 등재했다. 사진은 총 213장, 목록 대표 사진은 별도 29장이다.
원본 상세 페이지 26곳의 사진 수와 기존 파일 수를 직접 대조했다. 원본 사진 순서와 출처는 photo-source-manifest.json에 남겼다.
용인 편집·음악의 숲·진갈매갈은 원본에도 별도 상세 링크 없이 사진 1장만 제공하므로 해당 사진만 보여준다. 사진이 1장인 상세 페이지에는 자동 넘김 제어가 표시되지 않는다.

업체명과 출처는 대표 요청에 따라 공개한다. 촬영 및 디렉팅은 본유 스튜디오로 표시한다.
업체별 URL은 /services/photo/stay/25 등의 형태다. 미등록 유형·업체는 404로 처리한다.
자동 넘김 4.5초, 이전·다음, 썸네일, 키보드, 스와이프, 일시정지·재생을 지원한다.
마우스를 올리거나 브라우저가 숨겨지면 자동 넘김을 멈춘다. 키보드로 진입하거나 직접 사진을 고르면 재생 버튼을 누를 때까지 멈춘다. 움직임 줄이기 설정에서는 자동 재생하지 않는다.
