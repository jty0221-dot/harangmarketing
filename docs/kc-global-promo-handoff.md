## 2. 영상의 목적과 기조

- **목적**: 나라장터 홍보가 아니라 **케이씨글로벌(KC GLOBAL) 회사 홍보**. 자영업자·소상공인이 케이씨글로벌과 함께 공공조달 입찰에 참여하게 만드는 것.
- **기조**: 솔직하게 말한다. "낙찰은 확률 싸움"으로 시작해서 장점과 함께 주의사항을 모두 보여준다.
- **절대 넣지 않는 것**
  - "김과장이 말했다" 같은 특정 직원 인용·실명·연락처·주소
  - "15~30분이면 돈 번다" 같은 낚시성 후킹, 수익 보장 표현
  - 출처를 영상에서 확인시킬 수 없는 낙찰 사례 금액
  - 실물 지폐 도안(인물 얼굴이 보이는 5만원권 등)
  - 긴 대시(—) 문장부호
- **반드시 넣는 것**: 낙찰·수익 비보장, 세금 처리 전 예시, 계약서 확인, 세무사 상담, 세금 체납 시 지급 제한 가능성

## 3. 근거 자료 (영상 내용의 출처)

1. 케이씨글로벌 공식 설명 영상(16장 슬라이드, 2:20) 내용
   - 1인 자영업자도 참가 자격 충족 시 입찰 가능
   - 낙찰자는 추첨·적격심사·제안서 평가 등 공고에서 정한 방식
   - 입찰 방법 1:1 원격 교육, 공고는 공휴일 제외 매일 업데이트, 입찰은 의무 아님
   - 입찰은 사업자 본인 명의, 그 외 절차는 케이씨글로벌이 위임받아 진행
   - 7단계: 낙찰 확인·계약 → 물품 구매 → 납품 → 기관 검수 → 대금 청구·수령(사업자) → 비용 정산 → 순수익 배분
   - 정산 예시: 낙찰 1억 / 물품 6천만 / 운송·부대비 200만 / 순수익 3,800만 / 50:50이면 각 1,900만
   - 물품 하자 시 케이씨글로벌이 책임(교환), A/S는 판매처
   - 세금 체납·압류 시 대금 지급 지연·제한 가능
   - 마진율은 건마다 다르며 비용 범위·세금·정산 방법·지급 기한은 계약서에 명확히
2. 카카오톡 대화(담당자 설명)
   - 나라장터 가입·세팅 지원, 인증서·기업신용평가 비용 지원
   - 매일 공고 검토·수익성 선별, 입찰 금액 정보 제공
   - 구매·납품 비용 회사 선부담, 회사 직원이 납품
   - 입찰 시간 평일 18:00~익일 10:00
   - 가입비·컨설팅비 없음
   - 대금은 짧으면 한 달, 길면 반년 가까이

## 7. 제작 파이프라인 (재제작 시)

1. **목소리**: 대표 녹음(m4a) → 잡음 제거·EQ·컴프레서(자연보정 A안) → Whisper로 받아쓰기 → 줄 단위 자르기
2. **화면**: HTML 캔버스 모션그래픽 엔진(promo.html)에서 프레임 렌더 → Playwright로 24fps 캡처 → ffmpeg로 인코딩
3. **실사 클립**: Higgsfield Seedance로 생성한 6개 클립(식당 사장, 서류, 창고, 학교 납품, 네일숍, 사무실 실루엣)
4. **3D 일러스트**: Higgsfield gpt_image_2_5로 26장 생성 (장당 0.25크레딧)
5. **믹스**: 목소리 + 낮은 배경 패드 → 라우드니스 -16 LUFS

**누적 비용(Higgsfield 크레딧)**: Seedance 클립 약 640, 음성 약 21, 3D 이미지 약 6.5. 렌더·편집은 무료.
