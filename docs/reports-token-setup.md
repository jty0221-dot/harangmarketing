## 순서

### 1. Vercel 환경변수 화면 열기

브라우저에서 바로 이 주소로 간다.

```
https://vercel.com/jty0221-1680s-projects/harangmarketing/settings/environment-variables
```

메뉴로 찾아가려면: vercel.com 로그인 → **harangmarketing** 프로젝트 →
상단 **Settings** → 왼쪽 **Environment Variables**

### 2. 값 추가

화면 위쪽 입력칸 세 군데를 채운다.

| 칸 | 넣을 값 |
|---|---|
| **Key** (또는 Name) | `REPORTS_API_TOKEN` |
| **Value** | `MI6-j9xP2m0Ndg4d3TRWzGFV44ED0tH76lH3dnX20UM` |
| **Environments** | **Production** 체크 (Preview 도 같이 체크해두면 편하다) |

**Save** 를 누른다.

> 대소문자·하이픈까지 그대로 복사해야 한다. 앞뒤 공백이 붙으면 인증이 안 된다.

### 3. 재배포 — 이걸 빠뜨리면 안 된다

Vercel 은 환경변수를 저장해도 **다시 배포해야** 서버에 반영된다.

1. 상단 **Deployments** 탭
2. 맨 위(가장 최근) 배포 줄의 오른쪽 **···** 버튼
3. **Redeploy** → 확인
4. 1~2분 기다리면 Ready

### 4. 확인

대표님이 직접 확인하실 필요는 없다. 저(Claude)에게 **"토큰 넣었어"** 라고만 하면
시험 보고서를 하나 올려보고 끝까지 도는지 확인해서 알려드린다.

직접 해보시려면 명령 프롬프트에서:

```
cd E:\하랑\harang
node scripts/report.js --list
```

보고서 목록이 나오면 성공이다.
`인증 실패 — 토큰이 다릅니다` 가 나오면 값이 다르거나 재배포를 안 한 것이다.

## 자주 걸리는 곳

| 증상 | 원인 |
|---|---|
| `인증 실패 — 토큰이 다릅니다` | 값 오타 · 앞뒤 공백 · **재배포 안 함** |
| `REPORTS_API_TOKEN 이 없습니다` | 로컬 `.env.local` 문제. 보통은 이미 들어가 있다 |
| 저장했는데 그대로 | Environments 에 Production 체크를 안 함 |

## 토큰을 바꾸고 싶으면

아무 긴 무작위 문자열이면 된다. **Vercel 과 로컬 `.env.local` 둘 다** 같은 새 값으로 바꾸고 재배포한다.

## 왜 관리자 비밀번호를 안 쓰나

- 비밀번호를 스크립트나 대화에 남기지 않기 위해서다.
- 이 토큰이 새더라도 **보고서 등록·수정만** 가능하다. 회원·주문·정산은 건드리지 못한다.
- 언제든 값만 바꾸면 이전 토큰은 죽는다.
