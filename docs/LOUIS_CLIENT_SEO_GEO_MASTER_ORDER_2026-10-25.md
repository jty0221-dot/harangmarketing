## 최종 목표
현재 진행 중인 고객사의 실제 브랜드·지점·서비스권역을 식별하고, 검색량·네이버 검색/플레이스 노출·공개 웹 발견·ChatGPT 등 생성형 AI 추천 노출을 각각 **실제로 조회**하여 증거 기반으로 평가한다. 업체별로 바로 전달 가능한 개선 보고서를 작성하고, 우리가 관리 권한을 가진 홈페이지는 별도 PR로 기술 개선까지 준비한다.

## 0. 즉시 준수할 원칙
1. 시트의 관리명(울산입주청소, 부천누수 등)은 브랜드명이 아니다. 실제 사업체 식별 후 조사.
2. 사용자 확인 정본: 울산입주청소=열정클린, 세종 클린패스=클린패스, 의정부·양주 입주청소=청소GO(GO 영문), 군포 입주청소=두꺼비 홈케어, 부천누수=힘찬설비, 부천누수탐지=누수파이터.
3. 청설모 토탈케어 부천점의 공식/외부 번호 차이는 서브폰 운영이므로 오류 아님. 번호별 역할을 구분해 기록.
4. 두꺼비 홈케어 중복 계약행은 1개 업체로 묶되 계약·기간별 업무는 별도 기록. 2026-11 시작 예정 행은 미래 계약이므로 현재 진행 업무와 구분.
5. 네이버 공식 출처가 없는 순위 알고리즘 가중치·백분율을 절대 만들어내지 않는다.
6. 실제 검색하지 않은 질문을 '노출 안 됨'이라고 표시하지 않는다. 공개 웹 검색과 ChatGPT 추천은 다른 측정값이다.
7. 네이버 광고 키워드 도구 월 PC/MO 검색량을 조회하고 날짜와 원본 증거를 기록한다. 조회 권한 없으면 '미조회'로 표시하고 권한 요청을 남긴다. 데이터랩 상대지수를 월간 검색수로 대체하지 않는다.
8. 허위 리뷰, 조작된 후기, 순위 보장, 허위 지점/주소 생성, 의료광고 위반, 불법적인 트래픽 조작을 개선안에 포함하지 않는다.
9. 기존 고객사 사이트의 콘텐츠·디자인·연락처·상담 기능은 승인 없이 변경하지 않는다. 프로덕션 직접 배포 금지.
10. 27개 고객사 + 하랑마케팅 자체 1개를 기본 단위로 조사하되 브랜드/지점/서비스권역별 하위 작업을 추가한다.

## 2. 업체별 실제 식별
관리명 | 브랜드명 | 플레이스 표시명 | 공식 홈페이지 | 네이버 플레이스 URL | 실제 주소 | 지점 전화/서브폰 | 업종 | 제공 서비스 | 서비스 가능 지역 | 출처 URL | 확인 날짜 | 신뢰도.
확인 안 된 값은 미확인. 유사 상호가 있으면 전화/주소/공식 링크 교차 확인 후 확정.

## 3. 홈페이지 작업 가능 여부 (반드시 확인)
A. **직접 수정 가능**: 도메인 소유·소스 저장소·호스팅·관리자 권한·명시적 수정 허용 모두 확인. 코드 진단과 개선 PR 작성 가능. 운영 반영은 승인 후.
B. **홈페이지 있음 / 권한 없음**: 공개 진단만. 개발자/업체용 수정 요청서 생성. 무단 수정 금지.
C. **홈페이지 없음**: 홈페이지 코드 업무 제외. 플레이스·공식 블로그·카카오맵·구글 비즈니스 프로필·당근·숨고 등 해당 업종 채널의 정보 정비 제안.
D. **확인 중**: 홈페이지 유무 또는 소유권 미확정. 임의로 A나 C 판정 금지.
하랑마케팅 사이트는 Vercel harangmarketing + GitHub jty0221-dot/harangmarketing 확인됨. 기술 변경은 민수 팀장과 PR 리뷰.

## 4. 실측 검색
- 키워드 매트릭스: 지역(시/구/동/역세권) × 서비스/메뉴 × 의도(추천/가격/긴급/가족/혼밥/전문/시공 등).
- 모든 키워드에 월 PC/MO/합계 검색량, 조회일, 조회 도구/증빙 링크 또는 스크린샷.
- 네이버: 통합검색과 플레이스 결과를 분리하고 광고와 자연노출을 구분. 노출 위치·검색 일시·지역 조건 기록.
- 공개 웹: 검색 질의, 발견된 공식/제3자 출처, 브랜드 식별 증거, 경쟁 업체 기록.
- 생성형 AI: ChatGPT에 실제로 질문하고 원문 답변·추천 순서·인용 출처·실행 환경·시각 저장. 불가능하면 '미실행'으로 분리.
- 동일 키워드 1회 결과를 확정 순위로 일반화하지 않는다. 주요 키워드는 조건을 고정하여 반복 관측.
- 청설모: 포항 청소업체/상가청소/정기청소/후드청소, 부천 청소업체/사무실청소/식당청소, 김포 청소업체/입주청소/에어컨청소 등을 각각 실제 서비스 여부 검증 후 조회.
- 음식점: 지역/역명 + 맛집/점심/저녁/혼밥/데이트/회식/대표 메뉴. 의료: 지역/진료과/실제 진료범위. 청소/누수/인테리어/가설/소방: 지역/서비스/상황/견적/시공사례.

## 5. 개선안과 고객 전달문
각 업체에 대해:
- 1쪽 요약: 현재 확인된 강점, 실제 검색 결과, 미노출/미확인 항목, 상위 5개 기회 키워드(실측 검색량), 가장 시급한 3개 작업.
- 실행 작업표: 발견된 문제 / 증거 URL / 수정 대상 채널 / 수정 전후 제안 / 우선순위 / 담당 / 승인 필요 여부 / 검증 방법.
- 홈페이지 A: 메타/캐노니컬/robots/sitemap/구조화 데이터/서비스 지역 랜딩/사례/FAQ/내부링크 점검, 필요한 변경만 PR.
- 홈페이지 B: 수정 요청서, 업체/개발사 전달용 구체 문구.
- 홈페이지 C: 플레이스 정보·사진·메뉴/서비스·영업권역·리뷰 답변·실제 작업 사례·지도/외부 업체 프로필 정비.
- 고객에게 전달 가능한 쉬운 존댓말 버전과 내부 기술 버전 분리.
- 광고/의료·법률 등 규제 업종은 관련 표시광고 규정 준수.

## 6. 최종 산출물 및 완료 조건
1. MASTER 조사표 (CSV/Google Sheet): 전체 고객사/지점/질문/월 검색량/검색 결과/출처/개선 상태.
2. 고객사별 PDF: 모바일에서 읽기 쉽게, 업체당 최소 1페이지, 확인 결과와 미측정 구분.
3. 전체 PDF: 전체 요약, 지점별 주요 키워드, 검색량, 경쟁사, GEO 개선 우선순위, 실행 체크리스트.
4. 민수 팀장용 홈페이지 변경 PR 목록 + 검증 결과.
5. 조사 로그: 질문 전문, 시각, 엔진, 조건, 실제 결과, 캡처/URL.
**전수조사 완료**는 전체 대상의 약속한 질문이 실제 실행되고 결과 로그가 있을 때만 표기한다. 미실행이 있으면 진행률과 원인을 명시한다.

## 7. 협업/배포
